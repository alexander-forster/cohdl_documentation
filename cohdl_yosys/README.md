# cohdl_yosys

This directory contains the documentation of the [cohdl_yosys](https://github.com/alexander-forster/cohdl_yosys) formal verification library.

To run the notebooks, Yosys and its dependencies must be installed locally. You can use the `.devcontainer/Dockerfile` in this repo as a reference or work with the cohdl [docker image](https://hub.docker.com/r/cohdl/cohdl) directly.
