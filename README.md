# CoHDL documentation

This repository contains an introduction for the [CoHDL](https://github.com/alexander-forster/cohdl) hardware description language built in Python.

## repo structure

* cohdl_introduction

    Introduction to CoHDL language. The notebooks in the subdirectory `cohdl_introduction/with_output` contain the execution results (mostly the generated VHDL code) but are otherwise identical to the versions in `cohdl_introduction`.

* cohdl_yosys

    Contains documentation for the [cohdl_yosys](https://github.com/alexander-forster/cohdl_yosys) formal verification library.

* docs

    Contains the autogenerated output of the register abstraction example in cohdl_introducation. Only exists so the example can be hosted as a [GitHub Pages site](https://alexander-forster.github.io/cohdl_documentation/systemrdl_example_output/html_output/?p=).
